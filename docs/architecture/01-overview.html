Star Guard: обзор архитектуры

Основной путь — режим GitHub: RepoReportService через GithubHistoryService берёт дневную историю звёзд и активность по любому репозиторию из GitHub REST/GraphQL, а Star Tracker добавляет внутридневную детализацию из собственных снимков в PostgreSQL. Пул подозрительных аккаунтов — отдельный источник сигнала для score, собирается из форков отслеживаемых репозиториев. Индекс топ-1000 и GH Archive остаются резервным путём (app.report.source=index). GitHub закрыл список звёзд репозитория (/stargazers) 2026-06-30 — поэтому прежняя проверка пересечения звёзд по пользователям (C4) в режиме GitHub недоступна.
