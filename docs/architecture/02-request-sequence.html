Путь запроса отчёта

Режим GitHub: сервис отчёта берёт дневную историю звёзд и активность из GithubHistoryService (REST/GraphQL, кэш 5 минут). Если включён app.tracker.enabled, Star Tracker добавляет внутридневные точки из собственных снимков PostgreSQL. Итоговый snapshot передаётся в GithubScoringEngine, который возвращает score с explain по 6 проверкам.
