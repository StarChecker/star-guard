Пул подозрительных аккаунтов

Кандидаты собираются только из владельцев форков репозиториев, уже отслеживаемых Star Tracker, - без поиска пустых профилей и без перебора числовых ID, поскольку GitHub Search не даёт фильтр по количеству звёзд. Пул хранит top-N accounts по node ID (rename-safe), отклонённые кандидаты попадают в ограниченный cooldown. При построении отчёта совпадения со звёздами репозитория в окне [from, to) поднимают нижнюю границу score и добавляют отдельный ряд на график.
