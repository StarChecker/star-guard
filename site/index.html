Звёзды на GitHub можно купить

Star Guard ищет следы накрутки в событиях GH Archive и сводит их в одну оценку с объяснением.

  1. C1
    Всплески звёздсотни звёзд за пару часов при обычном фоне
  2. C2
    Свежие и пустые аккаунтызвёзды от аккаунтов младше месяца без активности
  3. C3
    Звёзды без активностимного звёзд, но почти нет коммитов, issues и PR
  4. C4
    Пересечение аккаунтоводни и те же аккаунты звездят одному набору репозиториев
  5. C5
    Суточный ритмзвёзды идут в неестественно ровном ритме

Установка за минуту

Пока расширения нет в Chrome Web Store, оно ставится вручную. Подходит любой браузер на Chromium: Chrome, Edge, Яндекс Браузер, Arc.

  1. Скачайте архивstar-guard-extension.zip и распакуйте его в папку
  2. Откройте страницу расширений chrome://extensions Вставьте адрес в строку браузера — ссылкой его открыть нельзя
  3. Включите «Режим разработчика»переключатель в правом верхнем углу
  4. Нажмите «Загрузить распакованное»и выберите распакованную папку
  5. Укажите серверСборка обращается к http://localhost:8080. Другой адрес задаётся в настройках расширения: иконка Star Guard → «Настройки» → «Адрес сервера» → «Проверить соединение». Свой сервер поднимается из клона репозитория: 
    $ docker compose up --build -d
  6. Откройте любой репозиторий на GitHubзначок появится рядом с кнопкой Star
